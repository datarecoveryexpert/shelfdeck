The problem

Stars are where good libraries go to be forgotten.

You save 20 repos a week. A month later you can't remember why, which project they were for, or that one of them shipped a breaking v2.0.

01

The star graveyard

No visual memory

Watching floods your inbox. ShelfDeck keeps a quiet feed for the items you track and flags breaking changes.

How it works

Start instantly. Grow only if you want to.

  1. Tier 1 · No login

    Instant local library

    Paste a URL. Metadata is fetched once from public APIs and stored in your browser. Shelves, notes and search all work offline.

  2. Tier 2 · Your API keys

    Release tracking & AI covers

    Add a GitHub or Hugging Face token to import stars and likes, track releases and generate covers. Keys never leave your device.

  3. Tier 3 · GitHub connect

    Sync & share

    A private shelfdeck-vault repo syncs Web, iOS and Android. A GitHub Action polls releases. Publish shelves to Pages.

Features

Built for people who actually ship.

Command palette

Ctrl K across shelves, tags, notes and README summaries.

Deep metadata

Stars, license, language, topics, releases, parameter counts, tasks and quantizations.

Smart collections

Rule-based shelves like "Rust CLI tools, MIT, added in the last 3 months".

Find alternative

Surface similar items you already saved, side by side in a comparison view.

Stacks

Group items into project recipes and record "replaces" and "depends on" links.

License & risk

Compatibility warnings, health badges and breaking-change flags.

Browser extension

One-click "Save to ShelfDeck" on GitHub and Hugging Face pages.

Awesome-list export

Turn any shelf into a polished AWESOME.md or a public gallery.

Cover engine

Every repo deserves a poster.

Most repositories have no artwork, so ShelfDeck makes some, on your device.

  1. Extract. Real social previews and README banners, with boilerplate cards and badges filtered out.
  2. Procedural. Instant, deterministic SVG posters in themes like Criterion Dev and Terminal Blueprint.
  3. AI. Use the codex or gemini CLI you already pay for, or bring your own image API key.

No ShelfDeck server

Your library lives in your browser or in your own GitHub repo. There is no central user database.

Keys stay local

Tokens go only to their own API endpoints and are never committed to any repository.

Plain JSON, forever

The vault is sharded JSON and WebP files. If ShelfDeck disappears, your data does not.
